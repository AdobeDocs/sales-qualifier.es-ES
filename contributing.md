# Contribución

Gracias por contribuir.

Siga estas directrices cuando contribuya a este proyecto.

## Código de conducta

Este proyecto sigue el [código de conducta](code-of-conduct.md) de Adobe. Al participar,
usted acepta mantener este código. Informar de comportamientos inaceptables a
[Grp-opensourceoffice@adobe.com](mailto:Grp-opensourceoffice@adobe.com).

## Guía del colaborador

Consulte la [guía para colaboradores de Adobe Docs](https://experienceleague.adobe.com/en/docs/contributor/contributor-guide/introduction).

## Formular una pregunta

Envíe un problema para hacer una pregunta. Los supervisores del proyecto analizan la dirección del proyecto
y las soluciones propuestas en los hilos de problemas.

## Acuerdo de licencia de colaborador

Todas las contribuciones de terceros requieren un contrato de licencia de colaborador (CLA) firmado.
El acuerdo otorga permiso a Adobe para redistribuir las contribuciones como parte
del proyecto. [Firmar el CLA](https://opensource.adobe.com/cla.html). Tienes que hacerlo
envíe el CLA de Adobe solo una vez.

## Revisiones de código

Enviar cambios como solicitudes de extracción. Los supervisores del proyecto revisan cada solicitud de extracción.
Para obtener más información, consulte [Acerca de las solicitudes de extracción](https://help.github.com/es/articles/about-pull-requests/).

## Conviértase en supervisor

Los supervisores tienen acceso de escritura completo y ayudan a guiar el proyecto. Creadores existentes
utilice un proceso de nominación interno y debe alcanzar un consenso diferido antes de que
invitar a un nuevo supervisor. Póngase en contacto con un supervisor existente si desea ser más
implicado.

## Problemas de seguridad

No informar de problemas de seguridad en este rastreador de problemas. En su lugar, [póngase en contacto con la seguridad de Adobe](https://helpx.adobe.com/es/security/alertus.html).
